# Medical Discharge Summary Generation using LLAMA and RAG
## Overview

This project focuses on generating structured medical discharge summaries from unstructured clinical transcripts using Meta’s LLaMA 3.1 Large Language Model (LLM).

The system processes multiple healthcare transcripts and automatically extracts important medical information, converting it into standardized JSON format for easier analysis and validation.

The generated outputs include:
- Patient Information
- Primary Diagnosis
- Secondary Diagnosis
- Complaints
- Vital Signs
- Investigations
- Treatments
- Discharge Medications
- Follow-up Instructions

The system primarily extracts and validates:
- Primary Diagnosis
- Secondary Diagnosis
- Discharge Medications

LLaMA 3.1 was used to process multiple patient transcripts sequentially and generate structured discharge summaries with medically relevant information.

To improve the reliability, consistency, and medical accuracy of the generated outputs, a Retrieval-Augmented Generation (RAG) validation pipeline was implemented using biomedical embeddings and vector similarity search.

The RAG system validates generated diagnoses and medications through embedding-based retrieval and medical term matching, helping reduce hallucinations and improve terminology consistency.

The project also includes comparison and validation of outputs generated by different Large Language Models (LLMs) against medical terminology databases.

This system demonstrates the application of Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) techniques in healthcare Natural Language Processing (NLP) for automated clinical documentation and discharge summary generation.

## Features

- Medical discharge summary generation
- Extraction of primary diagnosis
- Extraction of secondary diagnosis
- Medication extraction
- RAG-based medical term validation
- Embedding similarity search
- JSON structured outputs
- LLM comparison and evaluation
